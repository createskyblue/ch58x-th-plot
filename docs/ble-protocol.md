# TH-Plot 蓝牙传输协议

适用范围：协议版本 1，即系统信息命令返回的版本号为 1。本文档描述 GATT 通道、帧封装、全部命令的载荷布局与状态码，用于上位机及第三方客户端的互通开发。

## 协议格式

设备作为 GATT 从机，通过一条自定义特征收发 TinyFrame 帧。帧内整数分两种字节序：帧头字段大端，业务载荷中的多字节整数小端。

| 起始码 | 帧 ID | 载荷长度 | 消息类型 | 帧头校验 | 载荷 | 载荷校验 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| u8 | u16 | u16 | u8 | u16 | u8[] | u16 |

*   **起始码**：固定 `0x01`。
*   **帧 ID**：2 字节无符号整数，见「帧 ID」。
*   **载荷长度**：2 字节无符号整数，等于载荷字节数。
*   **消息类型**：1 字节无符号整数，见「命令列表」。
*   **帧头校验**：CRC16，覆盖起始码、帧 ID、载荷长度、消息类型共 6 字节。
*   **载荷**：长度等于载荷长度；为 0 时不发载荷，也不发载荷校验。
*   **载荷校验**：CRC16，只覆盖载荷。

CRC16 参数：初值 `0x0000`，反射多项式 `0xA001`，无末尾异或。载荷为 0 的帧固定 8 字节，非空帧为 `载荷长度 + 10` 字节。上行请求载荷上限 128 字节，下行帧载荷上限 246 字节。

**示例**（即时测量请求与响应，帧 ID 取 `0x8000`）：

```
01 80 00 00 00 04 CC 01                                    请求
01 80 00 00 09 84 3C 06 00 FD 00 64 02 40 E2 01 00 5F 0B  响应
```

## 通道与连接

| 项目 | 值 |
| :--- | :--- |
| 设备名 | `TH-Plot_XXXX`，XXXX 为芯片 UID 折叠出的 4 位十六进制 |
| 服务 UUID | `0xFFE0` |
| 写特征 UUID | `0xFFE1`，属性 Write 与 Write Without Response |
| 通知特征 UUID | `0xFFE4`，属性 Notify，需写 CCC 描述符 `0x0001` 才下发 |

广播由按键控制：长按 BOOT 打开 60 秒广播窗口，连接成功后窗口定时器停止、设备不进入睡眠；自然断开重新开一个 60 秒窗口；主动关闭会断开连接且不重开窗口。窗口只被连接续期，扫描不续期。

## 分片与重组

一帧可以跨多个 ATT 包。设备下行按协商 MTU 拆包，单个通知载荷为 `MTU - 3`，MTU 上限 247，即单包最多 244 字节；客户端必须按起始码、载荷长度、校验字段重组完整帧，不能把一条通知当成一帧。

上行写入单包不超过 `MTU - 3`。设备在系统信息 `0x81` 的 offset 29 发布建议写入分包大小（20～244），客户端按该值切片写入。设备接收缓冲 2048 字节，溢出时本次写入被丢弃；图片上传过程中溢出会记录为 IO 错误并在 commit 时上报。

## 帧 ID

上位机发起的帧 ID 最高位为 1，低 15 位递增循环；设备响应沿用请求的帧 ID。历史导出整段（`0x90`、`0x91`、`0x92`）沿用触发导出的 `0x10` 帧 ID，图片上传进度 `0xC6` 沿用 `0x40` 的帧 ID。取消与完成使用新的帧 ID，并在载荷中指定目标导出的帧 ID。

帧 ID、CRC 与格式检查只用于差错检测，不构成认证，也不防重放。

## 并发规则

设备有普通响应槽和异步结果槽各一个。普通请求应串行发送，等上一条响应返回后再发下一条。

*   历史导出期间允许只读查询（系统信息、用户寄存读取、设置读取、范围读取、即时测量），写入用户寄存、写设置、写范围、导入、重启返回 BUSY。
*   导入期间禁止导出、改设置、写激活码、重启；即时测量与只读查询可用。
*   同一时刻只允许一个导出或一个导入或一次图片上传。

设备端超时：即时测量 2 秒；导入与图片上传连续 10 秒无进展后中止；历史导出连续 3 秒没有成功收/发一帧后解冻；重启应答出队后延时 200 毫秒执行复位。

## 通用响应

成功响应类型为请求类型加 `0x80`，载荷按各命令定义。错误响应统一为 `0xFF`：

| 字段 | 类型 | 长度（字节） | 取值 |
| :--- | :--- | :--- | :--- |
| 状态码 | u8 | 1 | 见下表 |
| 请求类型 | u8 | 1 | 出错请求的原始类型 |

| 状态码 | 名称 | 含义 |
| :--- | :--- | :--- |
| 1 | INVALID | 长度错误、格式错误、取值越界、目标不匹配 |
| 2 | BUSY | 有导出、导入、上传或刷屏作业占用 |
| 3 | UNAVAILABLE | 该构建没有对应能力，例如未实现复位 |
| 4 | IO_ERROR | Flash 读写失败、加密不可用、CRC 不匹配 |
| 5 | TIMEOUT | 等待设备内部异步结果超时 |
| 6 | NOT_ACTIVATED | 操作需要激活权限 |

未定义的请求类型一律返回 INVALID。载荷长度或取值范围不符合该命令规定时，在进入业务处理前即返回 INVALID。

## 命令详解

### 读取系统信息 0x01

请求载荷为空。响应载荷 52 字节：

| 偏移 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 0 | 协议版本 | u8 | 固定 1 |
| 1 | 硬件 UID 可用标志 | u8 | 0 不可用，1 可用 |
| 2 | 用户存储可用标志 | u8 | 0 不可用，1 可用 |
| 3 | 传感器类型 | u8 | 0 未检测到，1 AHT20，2 SHT40 |
| 4 | 芯片 UID | u8[8] | SDK 唯一 ID，不是 MAC |
| 12 | 芯片信息 | u32 | SDK chip_info |
| 16 | 长期区容量 | u32 | 8640 点 |
| 20 | 最近区容量 | u32 | 1440 点 |
| 24 | 设备运行毫秒 | u32 | 会回绕，不是 Unix 时间 |
| 28 | 用户寄存上限 | u8 | 64 |
| 29 | 建议写入分包大小 | u8 | 20～244，按 `MTU - 3` 计算并限幅 |
| 30 | 密钥模式 | u8 | 0 不可用，1 出厂密钥，2 测试密钥 |
| 31 | 标志位 | u8 | bit0=当前构建含模拟历史，其余为 0 |
| 32 | 固件编译时间 | ASCII[20] | `Mmm dd yyyy hh:mm:ss`，日号空格补齐 |

编译时间为固件构建时刻，增量编译时可能早于整镜像的链接时间。设备始终发满 52 字节。

### 读取用户寄存 0x02

请求载荷为空。响应载荷为 `长度 u8` 加该长度的原始字节，长度上限 64。设备不做 trim、截断或加解密，读到多少返回多少。读取失败返回 IO_ERROR。

### 写入用户寄存 0x03

| 字段 | 类型 | 长度（字节） | 取值 |
| :--- | :--- | :--- | :--- |
| 数据 | u8[] | 0～64 | 任意原始字节，0 字节表示清空 |

响应载荷为 1 字节状态 0。超长返回 INVALID；历史占用期间返回 BUSY。设备写后回读校验，内容相同时不重复擦写，写失败返回 IO_ERROR。

### 读取即时测量 0x04

请求载荷为空。响应载荷 9 字节：

| 偏移 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 0 | 状态 | u8 | 0 有效，4 传感器测量失败（其后数值为 0） |
| 1 | 温度 | i16 | 0.1 ℃，小端 |
| 3 | 湿度 | i16 | 0.1 %RH，小端 |
| 5 | 测量耗时 | u32 | 毫秒，小端 |

设备真正启动一次非阻塞采样，最多等待 2 秒，不使用缓存值，也不写历史。2 秒内没有结果返回 TIMEOUT；已有一条测量请求在等待结果时，新的请求返回 BUSY。

### 重启设备 0x05

请求载荷为空，响应载荷为 1 字节状态 0。设备先把响应排进发送队列，200 毫秒后执行软件复位，保证应答能发出去。

历史导出进行中返回 BUSY。复位范围是整颗芯片，BLE 窗口状态不保留，复位后必须长按 BOOT 重新打开广播窗口才能再次连接。

### 设备设置 0x07 / 0x08

读取请求载荷为空，响应载荷 2 字节；写入请求载荷 2 字节，响应载荷 1 字节状态 0。

| 偏移 | 字段 | 类型 | 取值 |
| :--- | :--- | :--- | :--- |
| 0 | 记录模式 | u8 | 0 长期 30 天 5 分钟（最近一天仍为分钟点），1 完整 7 天分钟 |
| 1 | 变化刷新 | u8 | 0 关闭，1 开启 |

任何一字节大于 1 或长度不为 2 返回 INVALID。写入时历史占用或刷屏作业进行中返回 BUSY，存储失败返回 IO_ERROR。切换记录模式会清空设备历史，并把当前最后读数作为新起点。

### 屏幕时间范围 0x09 / 0x0A

读取请求载荷为空，返回当前范围索引；写入请求载荷为 1 字节索引，返回 1 字节状态 0。索引越界返回 INVALID。导入期间或已接受重启请求时写入返回 BUSY，读取不受影响。

| 索引 | 范围 | 索引 | 范围 |
| :--- | :--- | :--- | :--- |
| 0 | 1 小时 | 6 | 12 小时 |
| 1 | 2 小时 | 7 | 1 天 |
| 2 | 3 小时 | 8 | 3 天 |
| 3 | 4 小时 | 9 | 7 天 |
| 4 | 6 小时 | 10 | 15 天 |
| 5 | 8 小时 | 11 | 30 天 |

上电默认索引 7。写入成功只表示选择已接受，物理屏幕刷新由显示作业排队完成，连续切换会合并为一次刷新。

### 浏览器对时 0x0B

| 字段 | 类型 | 长度（字节） | 取值 |
| :--- | :--- | :--- | :--- |
| 本地时间 | u32 | 4 | 浏览器本地墙钟的 Unix 秒（`Date.now()` 加本地时区偏移），小端 |

载荷必须恰好 4 字节，超出 2020-01-01 至 2100-12-31 的取值返回 INVALID，其余返回状态 0。

设备把它换算成业务时钟偏移，`业务时间 = 主 RTC 读数 + 偏移`，不改写主 RTC，因此对时不重连、不断链。对时成功且当前处于万年历模式时，设备请求一次整屏刷新；温湿度模式只更新业务时间。掉电后重连需要重新对时。

### 导出全量历史 0x10

请求载荷为空，设备拒绝时返回 BUSY 或 UNAVAILABLE。接受后设备冻结历史写入，并按序推送 `0x90`、若干 `0x91`、`0x92`，全部沿用 `0x10` 的帧 ID。

#### 0x90 开始

| 偏移 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 0 | 版本 | u8 | 固定 1 |
| 1 | 标志位 | u8 | 取值 1 或 3：bit0 固定为 1，bit1 置位表示当前历史含模拟预填数据 |
| 2 | 长期区点数 | u16 | 0～8640 |
| 4 | 最近区点数 | u16 | 0～1440 |
| 6 | 保留 | u16 | 0 |
| 8 | 长期区步长 | u32 | 秒，5 分钟模式为 300，7 天模式为 60 |
| 12 | 最近区步长 | u32 | 秒，固定 60 |
| 16 | 有效跨度 | u32 | 秒，是时长不是绝对时间 |
| 20 | 明文字节数 | u32 | 等于 `(长期区点数 + 最近区点数) × 4` |

#### 0x91 数据

| 偏移 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 0 | 流偏移 | u32 | 本次导出的输出偏移，不是查询参数 |
| 4 | nonce | u8[12] | 明文发送 |
| 16 | 密文 | u8[] | 长度不超过 192 且为 4 的倍数 |

载荷长度 16～208 字节。明文顺序为长期区有效点从旧到新，接着最近区有效点从旧到新，每个点为 `温度 i16 | 湿度 i16`，单位 0.1。

密文为 ChaCha20（RFC 8439），块计数从 1 开始，密钥由设备侧持有，每帧一个独立随机 nonce。同一帧因拥塞被重发时密文完全相同，客户端应把偏移相同且内容相同的帧视为重复而不计入进度。

#### 0x92 结束

| 偏移 | 字段 | 类型 | 说明 |
| :--- | :--- | :--- | :--- |
| 0 | 明文字节数 | u32 | 与开始帧一致 |
| 4 | 冻结耗时 | u32 | 毫秒，不含等待确认的时间 |

客户端校验偏移连续、累计字节数等于总数、密文帧之间 nonce 不重复后，发送 `0x12` 确认。设备在目标匹配、已发出结束帧、本地发送队列排空时接受确认并解冻，随后回 `0x94`；客户端收到 `0x94` 后进度才算 100%。

导出没有分页和续传参数。取消、断连、关闭通知、发送或加密失败、连续 3 秒没有成功收/发一帧都会解冻，客户端需要从头重新请求。

### 取消 0x11 与完成 0x12

两者请求载荷都是目标导出的帧 ID（u16，小端），响应载荷为 1 字节状态 0。当前没有进行中的导出，或载荷中的帧 ID 与实际导出帧 ID 不一致时返回 INVALID。

### 导入测试历史 0x20 至 0x23

导入需要激活状态，否则返回 NOT_ACTIVATED 并中止当前导入。

#### 0x20 开始

| 字段 | 类型 | 长度（字节） | 取值 |
| :--- | :--- | :--- | :--- |
| 版本 | u8 | 1 | 固定 1 |
| 记录模式 | u8 | 1 | 必须等于当前设备设置 |
| 长期区点数 | u16 | 2 | 0～8640 |
| 最近区点数 | u16 | 2 | 1～1440 |

响应载荷为 1 字节状态 0。刷屏作业进行中、已接受重启或历史占用时返回 BUSY；模式不匹配或点数越界返回 INVALID。开始成功后设备清空已发布的历史计数并独占存储，未完成的数据不能被绘图或导出读取。

#### 0x21 数据

| 字段 | 类型 | 长度（字节） | 取值 |
| :--- | :--- | :--- | :--- |
| 点数偏移 | u16 | 2 | 第一块必须为 0，之后等于上一条响应的下一个偏移 |
| 样本 | u8[] | 4～120 | 每点 `温度 i16` 加 `湿度 i16`，最多 30 点 |

载荷长度 6～122 字节。顺序为先长期区从旧到新，再最近区从旧到新。温度取值 -400～1250，湿度 0～1000（0.1 单位）。偏移不连续、重复、越界或任一点越界都返回 INVALID，整块校验通过才写入。

响应载荷 2 字节，为下一个点数偏移（u16，小端）。

#### 0x22 提交

| 字段 | 类型 | 长度（字节） | 取值 |
| :--- | :--- | :--- | :--- |
| 样本 CRC32 | u32 | 4 | 覆盖按导入顺序拼接的全部样本字节，小端 |

CRC32 参数：初值 `0xFFFFFFFF`，反射多项式 `0xEDB88320`，末尾异或 `0xFFFFFFFF`（`123456789` 的计算结果为 `0xCBF43926`）。偏移、元数据与帧封装都不参与计算。点数和 CRC 同时匹配才发布历史并请求刷新当前时间范围，否则返回 INVALID。

#### 0x23 取消

请求载荷为空，响应载荷为 1 字节状态 0。断连、关闭通知、激活失效、连续 10 秒没有成功推进也会自动取消。开始替换之后取消会留下空历史，设备不保留旧数据副本。导入的数据只在 RAM 中，重启后丢失并恢复正常采样。

### 自定义图片 0x40 至 0x45

图片固定 400×300 单色位图，15000 字节，存储于设备 Flash，由独立页面显示。本节全部命令要求激活状态，未激活返回 NOT_ACTIVATED。

#### 0x40 开始

| 字段 | 类型 | 长度（字节） | 取值 |
| :--- | :--- | :--- | :--- |
| 宽度 | u16 | 2 | 固定 400 |
| 高度 | u16 | 2 | 固定 300 |
| 数据长度 | u32 | 4 | 1～15000 |
| 图片 CRC32 | u32 | 4 | 全图校验，提交时校验 |

响应载荷为 1 字节状态 0。尺寸不符或长度越界返回 INVALID；历史占用或刷屏作业进行中返回 BUSY；Flash 擦除失败返回 IO_ERROR。

#### 0x41 数据

| 字段 | 类型 | 长度（字节） | 取值 |
| :--- | :--- | :--- | :--- |
| 偏移 | u32 | 4 | 必须等于设备已接收字节数 |
| 数据 | u8[] | 1～116 | 位图分片 |

载荷长度 5～120 字节。偏移不连续返回 INVALID。该命令不逐帧应答，避免流式上传被应答拖慢。

#### 0xC6 接收进度

设备在已接收字节数比上次上报增加 1024 字节或达到总长度时，用 `0xC6` 通知已接收字节数（u32，小端），帧 ID 延用开始帧。客户端据此显示进度，最终以 `0x42` 的应答为准。

#### 0x42 提交

| 字段 | 类型 | 长度（字节） | 取值 |
| :--- | :--- | :--- | :--- |
| 图片 CRC32 | u32 | 4 | 与开始帧一致 |

已接收长度必须等于开始帧声明的长度且 CRC 匹配，否则返回 IO_ERROR。成功后图片保存到 Flash、自动置为启用，并立即切到该图片页；响应载荷为 1 字节状态 0。

#### 0x43 取消

请求载荷为空，响应载荷为 1 字节状态 0，丢弃本次上传。上传期间连续 10 秒无数据到达时设备自动取消，并记住该错误，下一次 `0x42` 返回 TIMEOUT。

#### 0x44 / 0x45 图片页开关

读取请求载荷为空，响应载荷 1 字节开关值；写入请求载荷 1 字节开关值，响应载荷 1 字节状态 0。开关值必须为 0 或 1，否则返回 INVALID。设备尚未保存过有效图片时写入返回 INVALID，上传进行中返回 BUSY，存储失败返回 IO_ERROR。

## 数据编码约定

*   温度与湿度一律为 int16，单位 0.1，小端；温度合法范围 -400～1250，湿度 0～1000。
*   历史每点 4 字节：`温度 i16 | 湿度 i16`，容量为长期区 8640 点加最近区 1440 点，合计 10080 点、40320 字节。
*   5 分钟模式：长期区步长 300 秒覆盖约 30 天，最近区 60 秒覆盖约 1 天，滚动时把最旧的 5 分钟压成长期区 1 个点。
*   7 天模式：长期区步长 60 秒，与最近区合起来提供 10080 个分钟点，覆盖约 7 天。
*   历史没有每点时间戳，只有名义粒度与总跨度，客户端不得据此伪造精确采样时刻。
*   CRC 与格式检查用于发现传输错误，不构成数据认证；历史数据的保密性由独立的密钥加密提供，密钥不在协议中传输。
